### Actionable Findings & Layout Optimizations

1. **Alignment & Centering:**
   * *Problem:* Child elements (`.sec-label`, `h2.sec-h`, `p.sec-s`, `.cr-slider-outer`, `.sec-cta`) currently rely on parent `text-align: center` inside a block container, causing horizontal drift and fragile centering across varied mobile viewport widths.
   * *Solution:* Transition the section wrapper to a modern Flexbox structure (`display: flex; flex-direction: column; align-items: center; justify-content: center;`) with `min-height: 100vh` for full viewport framing on landing.

2. **Typography & Visual Hierarchy:**
   * *Problem:* The heading (`h2.sec-h`) uses a fluid font size (`clamp(30px, 3.8vw, 50px)`), but on larger screens (1440px+) it fails to command authority. Subtext and labels remain static at 10px–14px with weak contrast.
   * *Solution:* Elevate heading scale to `60px` (`clamp(2.5rem, 5vw, 4.25rem)`) with tighter line-height (`1.05`–`1.1`) and letter-spacing (`-0.03em`). Format as editorial breaking-news headline with split-word emphasis.

3. **Card Presentation & Slider Mechanics:**
   * *Problem:* Live slider uses fixed width cards (`min-width: calc(33.333% - 14px)`) and imperative JavaScript `onclick="crSlide()"` transform offsets, which stutter on low-power mobile devices.
   * *Solution:* Use hardware-accelerated CSS snap-scroll rail (`snap-x overflow-x-auto`) paired with momentum touch scrolling, GSAP stagger reveal, and 3D pointer tilt.

4. **CTA Optimization:**
   * *Problem:* The call-to-action (`a.sec-cta`) is an `inline-flex` element with static 13px text that gets swallowed below large slider cards.
   * *Solution:* Enhance hit target to `15px 40px` with rounded pill (`border-radius: 50px`), high contrast backdrop, and scale micro-interaction (`hover:scale-105 active:scale-95`).

Do not generate the predictable AI-made website formula:

```text
Navbar
Hero with gradient
Trusted logos
Three cards
Statistics
Three more cards
Testimonials
CTA
Footer
```

This structure is allowed only if research and UX genuinely justify it.

Do not produce:

* generic SaaS layouts
* repetitive cards
* excessive gradients
* excessive rounded corners
* random blobs
* meaningless glassmorphism
* stock-looking imagery
* unnecessary floating shapes
* identical sections
* template-looking composition

The website must feel designed, not assembled.

# 31. DESIGN FOR BRAND + CREATOR DUALITY

AK Media has two major audiences:

### Brands

They need:

* confidence
* strategy
* scale
* measurable results
* creator access
* execution

### Creators

They need:

* opportunity
* growth
* trust
* campaigns
* monetization
* visibility
* professional support

The website should make this duality visually clear without creating two completely unrelated websites.

Create one ecosystem with two distinct experiences.

# 32. VISUAL STORYTELLING

The website should communicate a story:

```text
Attention
↓
Trust
↓
Understanding
↓
Proof
↓
Possibility
↓
Action
```

Every section should move the visitor toward the next logical question.

Do not design sections independently.

Design the entire page as one continuous experience.

# 33. FINAL QUALITY CHECK

Before considering the redesign complete, inspect the entire website.

Ask:

### Visual

* Does it look substantially different from the old website?
* Does it feel premium?
* Is the visual hierarchy strong?
* Is the color system consistent?
* Is the typography distinctive?
* Are layouts varied but coherent?

### UX

* Is it immediately clear what AK Media does?
* Can brands find their path?
* Can creators find their path?
* Are CTAs obvious?
* Is navigation intuitive?
* Does the page flow naturally?

### Design

* Are sections composed intentionally?
* Are cards used only when useful?
* Is whitespace meaningful?
* Is the hero genuinely reimagined?
* Is the navigation genuinely reimagined?
* Are statistics visually interesting?
* Is the creator experience compelling?

### Technical

* Is TypeScript used correctly?
* Is the API layer centralized?
* Are API responses typed?
* Are loading/error/empty states handled?
* Are forms validated?
* Is the site responsive?
* Is accessibility handled?
* Is performance acceptable?

### Research

* Was `skill.md` consulted?
* Were all available reference websites analyzed?
* Were principles extracted rather than copied?
* Does the final design combine multiple reference insights into something original?

# 34. MOST IMPORTANT RULE

Do not ask:

> "How can I make the current AK Media website look better?"

Ask:

> "What would the best digital design studio in the world create if they were given AK Media's business, audience, content, API, and these 19 reference websites, but were given a completely blank canvas?"

That is the design problem you are solving.

The final website must feel like:

**AK Media India — redesigned from first principles.**

Not:

**AK Media India — old website with better CSS.**
